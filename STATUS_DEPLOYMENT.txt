🚀 PRÓXIMOS 5 PASSOS (Em Ordem)
═════════════════════════════════════════════════════════════════════════════

  [ 1 ] Fazer commit do código
        $ git add .
        $ git commit -m "Setup Vercel deployment"
        $ git push
        
  [ 2 ] Deployar Backend na Vercel
        → Acesse https://vercel.com/new
        → Selecione repositório
        → Root Directory: backend
        → Deploy
        → Receba URL
        
  [ 3 ] Adicionar OPENAI_API_KEY
        → Painel Vercel → Settings → Environment Variables
        → Adicione OPENAI_API_KEY
        → Redeploy
        
  [ 4 ] Deployar Frontend na Vercel
        → Acesse https://vercel.com/new
        → Selecione repositório
        → Root Directory: frontend
        → VITE_API_URL = URL do backend
        → Deploy
        
  [ 5 ] Testar
        → Abra frontend
        → Teste câmera
        → Analise uma carta
        → 🎉 Pronto\!
